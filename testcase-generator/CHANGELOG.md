# CHANGELOG

## 0.7.0

- Markdown 成为唯一默认用例产物；Excel 仅在用户明确要求时导出。
- 移除 HTML 生成器及 `--excel`、`--no-html` 等旧导出语义。
- 新增共享 schema 层，统一完整 13 列、目标十列、追踪轻量变体、字段别名和合法枚举。
- validator 新增 `--schema` 与 `--br-source`，支持真实 Markdown 行号、逐行必填、未知/未覆盖 BR 及明确关键 BR 的 P0 覆盖检查。
- Excel 默认跳过 `00.` 大纲；保留模板原有内容并追加用例 sheet；继续支持多表格。
- 测试数据规范去项目化；删除固定状态时间阈值和重复检查表，集中保留人性化、可执行和可判定标准。
- `.md` 改为直接读取；其他受支持文档格式才执行转换。

## 0.6.0

- 人性化表达成为默认写法；确立完整 13 列和目标十列双 schema。
- validator 支持字段别名、全局唯一编号和自然标题。

## 0.5.0

- 明确仅服务游戏项目；增加 BR 追溯和 13 列模板。

## 0.3.0

- 引入规模档位、大纲和分模块生成，增加 504 降级策略。

## 0.1.0

- 初版：覆盖维度、质量标准、合并规则和脚本骨架。
